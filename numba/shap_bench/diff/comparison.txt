READING THE DIFFERENTIAL FLAMEGRAPHS
Weights are estimated sampled cycles per completed call, rounded to integers; no total-share normalization.
Only original_kernel/optimized_kernel prefixes and compiler ABI tags are stripped to align names.
diff-before.svg uses original widths; diff-after.svg uses optimized widths. Blue=less, red=more attributed cost.
Inlining changes attribution: red can mean work moved into a caller, not a regression. Widths auto-scale between files.
Folded stacks expand inline frames; flat perf report may group that code under the enclosing symbol, so leaf shares can differ.

LIMITATIONS
JIT leaf symbols resolve well, but missing unwind records can truncate or corrupt caller chains.
Zero unknown markers does not prove complete stacks. A tiny unresolved leaf is reported, not discarded.
The optimized scoring helper has no native NRT calls; the entry point still allocates its output array.
No sampled refcount leaves does not prove zero refcounts. Original refcounts need not all belong to XOR temporaries.
Ordinary cycles sampling can skid; assembly percentages are not precise instruction latencies.
Each hardware-counter result is one gated run, not a repeated-trial estimate. Governor remains powersave.
Raw perf data requires Linux and matching binary/source paths; jitdump ELF files retain their original paths.
